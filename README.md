# TetoTV Releases

Official stable TetoTV release downloads.

## Downloads

Public stable builds use **v1.x** version numbers. Download the current APK from this repository's [Releases](https://github.com/LindersOSX/TetoTV-Releases/releases) page.

TetoTV is distributed as one **Universal APK** with support for both 32-bit ARM (`armeabi-v7a`) and 64-bit ARM (`arm64-v8a`) streaming devices. You do not need separate 32-bit and 64-bit downloads.
